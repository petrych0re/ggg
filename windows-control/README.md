# Telegram AI Bot Control (Windows)\n\nA local desktop controller for starting/stopping a Python Telegram bot and viewing its output. It runs only on this PC.\n\n## Build\nPush this folder to GitHub, then open **Actions** and run the **Build Windows EXE** workflow. Download the `TelegramAIControl-Windows` artifact from the completed run.\n\n## Use\n1. Extract the downloaded artifact and run `TelegramAIControl.exe`.\n2. Select your existing `bot.py`.\n3. Create/select a local `.env` file and enter your own credentials. Never upload `.env` to GitHub or share screenshots containing tokens.\n4. Press Start Bot. MySQL Server and Python dependencies required by your bot must be installed separately.\n\nThe controller executable does not bundle your bot or its Python dependencies; it launches the selected bot with the current Python interpreter. Install Python on Windows and install your bot's requirements first.\n
